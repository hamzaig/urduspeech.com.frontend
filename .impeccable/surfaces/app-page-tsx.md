# Homepage

Mode: Persuade

The visitor needs to see how a recording becomes captions in a script their audience can read.

## Direction contract

The owner cited ElevenLabs and Wispr Flow for the homepage. The page uses their clarity and restraint as a quality reference. It has a centered, two-line masthead, a direct trial action, and a two-column parallel-text caption demo in ink and soft green. The four language controls translate the same set of selectable example lines. The demo presents output that can be copied. On phones the selected caption sits above the source cues. Studio remains a separate release.
